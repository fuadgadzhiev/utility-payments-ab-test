# A/B Test Analysis: Utility (ЖКУ) Payment Form

Продуктовый анализ результатов A/B теста новой упрощенной формы оплаты жилищно-коммунальных услуг (ЖКУ). Проект направлен на оценку влияния изменений пользовательского интерфейса на ключевую метрику воронки.

##  Описание проекта
В ходе эксперимента оценивалась эффективность нового дизайна формы оплаты по сравнению со старой версией. 
* **Контрольная группа (A):** Старая форма оплаты.
* **Тестовая группа (B):** Упрощенная форма оплаты.
* **Целевая метрика:** Конверсия из открытия формы (Шаг 1) в успешную оплату (Шаг 4).

##  Используемые инструменты и библиотеки
* **Python** (Pandas)
* **Статистический анализ:** Statsmodels (`proportions_ztest`)
* **Визуализация:** Matplotlib, Seaborn
* **Среда:** Jupyter Notebook

##  Ключевые результаты
* Конверсия в группе **A** составила **65.73%**.
* Конверсия в группе **B** составила **80.40%**.
* Прирост конверсии: **~14.67 процентных пункта**.
* **Статистическая значимость:** Z-тест для долей подтвердил высокую статистическую значимость различий ($p\text{-value} < 1.53 \times 10^{-10}$). Нулевая гипотеза отвергнута.

##  Бизнес-рекомендации
Новая упрощенная форма демонстрирует мощный положительный эффект на пользовательский опыт и конверсионную воронку. Рекомендовано полностью раскатить изменения на всю аудиторию.

##  Структура репозитория
* `ab_test_analysis.ipynb` — Jupyter Notebook с полным циклом анализа (предобработка, расчеты, статтесты, визуализация).
* `users.csv` — датасет с информацией о пользователях (группа, возраст, город, устройство).
* `payments.csv` — датасет с логами шагов платежной воронки.
